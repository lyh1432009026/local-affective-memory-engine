📖 主流聊天软件配置图文步骤
选择你正在使用的客户端，照着两步搞定：
🍒 Cherry Studio 接入
  1. 打开设置 → 模型服务 → 点击 + 添加服务商。
  2. 提供商选 OpenAI 兼容，Base URL 填入 http://127.0.0.1:4100/v1。
  3. API Key 随便填（如 sk-local），模型填入 gemini-3.8-flash 即可开聊！
💬 Chatbox / NextChat 接入
  1. 打开设置 → 模型提供商选择 OpenAI API。
  2. API 域名/地址填入：http://127.0.0.1:4100。
  3. API Key 填入任意字符串，保存即可享受无损记忆与情感对话！
⚡ DeepSeek Harness (DSH)
  1. 引擎已原生支持 Cordis 内核，配置文件已预设 local-affective-engine。
  2. 重启 DSH 客户端，模型列表自动出现 deepseek-flash (伴生记忆神经版)。
💻 Cursor / VSCode 接入
  1. 进入 Cursor Settings → Models → 开启 Override OpenAI Base URL。
  2. 填入 http://127.0.0.1:4100/v1，ApiKey 填 sk-local。
  3. 在对话框提问时，代码理解与记忆上下文自动由引擎注入增强。
