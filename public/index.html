🚨 DeepSeek Harness (DSH) 联网搜索排坑指南

从官方原生切到本引擎后，若客户端搜索报红 Error: DeepSeek search has no API key for "DEEPSEEK_API_KEY"，这是由于 DSH 的第三方网关机制所致。任选以下一种方式即可彻底解决：

方式 1：环境变量法（最省心 · 推荐）
在上方填入 Key 并点击「一键写入系统环境变量」，重新启动客户端即可。
方式 2：账号额度穿透插件（免配 Key · 白嫖官方额度）
让第三方网关会话也能继续复用 DSH 已登录账号的官方搜索额度。
方式 3：第三方免 Key 搜索源（Tavily / Exa）
切换搜索后端为免 Key 的 Tavily/Exa 通道，彻底脱离 DeepSeek 限制。
⚠️ 网页获取报错 resolves to a non-public IP address？
这是由于开启了 Clash / sing-box 的 FakeIP 模式 (198.18.x.x) 触发了客户端的 SSRF 内网防护拦截。
👉 解法：将代理软件的 DNS 模式切为 redir-host，或在 DSH 中安装放行插件： dsh plugin install bemarkt/dsh-fakeip-compat [复制命令]

2. 其它通用客户端（Cherry Studio / Chatbox / NextChat / Cursor）：

  • 自定义端点填入 http://127.0.0.1:4100/v1，密钥填任意字符串即可。
  • 客户端自带的联网搜索功能请在对应客户端的「工具 / 联网」设置中自行配置引擎密钥。
